# Game and modding curriculum sources

Reviewed September 23, 2026. Training answers are original concise explanations, not copied pages or Discord conversations.

- [Gorilla Tag's developer-published Steam page](https://store.steampowered.com/app/1533390/Gorilla_Tag/): VR, arm-based locomotion, tag/infection, social play, environments, Another Axiom.
- [Another Axiom](https://www.anotheraxiom.com/about): project/developer background.
- [Gorilla Tag Fan Content & Mod Policy](https://www.gorillatagvr.com/fan-content-mod-policy): distinguish community projects from official tools and approved distribution. Avoid promising that any private room or mod is automatically permitted.
- [BepInEx plugin documentation](https://docs.bepinex.dev/articles/dev_guide/plugin_tutorial/2_plugin_start.html): plugin metadata, Unity Mono plugin concepts; other backends require the matching framework/build.
- [BepInEx troubleshooting](https://docs.bepinex.dev/articles/user_guide/troubleshooting.html): compatibility and logs.
- [Harmony documentation](https://harmony.pardeike.net/v2/articles/intro.html): runtime method patches, prefixes, and postfixes.
- [Fabric player guides](https://docs.fabricmc.net/players/): Minecraft loader ecosystem, versions, dependencies, and troubleshooting.
- Local `project_facts.py`, `configs/model.yaml`, and the repository's `ALL_MODELS_API_GUIDE.md`: model identity, architecture, real family members and endpoints.
- Existing reviewed curriculum plus `public_geography.py` and its source report: general-skill replay, awareness, and capital-city retention.

The curriculum describes community roles and practices, not an unverifiable list of Discord members, current mod-menu recommendations, prices, or download links. Raw Discord logs remain diagnostic evidence rather than authoritative answers.

Dataset filters check structure, repeated prose, empty answers, prompt-marker/encoding leaks, private log fields, generic nonanswers, and wrong assistant-persona claims. They deliberately preserve jokes and harmless nonsense. These filters run at dataset build time. The game update adds no runtime factual-response replacement or nonexistent-model detector.

The raw evaluation bypasses deterministic handlers and reports rough keyword coverage alongside every complete reply. It is a fixed project test, not an independent benchmark; correct keywords do not guarantee a correct answer.
