# ChudGPT-Public API

Hosted chat and API endpoint for the 20,999,184-parameter ChudGPT-Public model.

Set the Space variable `MODEL_REPO_ID` to the Hugging Face model repository ID. Private Spaces require callers to provide a Hugging Face token with read access.
